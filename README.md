# ALEPH 자기소개 페이지

IT 및 보안 인프라 분야를 배우고 있는 비전공자의 장점과 취미를 소개하는 한 페이지입니다.

## 공개 범위

- 공개: IT 및 보안 인프라 분야 비전공자, 장점, 취미
- 비공개: 출신지 및 출신대학, 이전 회사명, 수험번호 등 개인 식별 정보

## 제출 확인

- `index.html`을 루트에 두어 GitHub Pages에서 바로 열릴 수 있게 구성했습니다.
- 근거 이미지는 `public/evidence/`에 보관했습니다.
- 카드별 점검 결과는 `CARD1_CHECK.md`부터 `CARD5_CHECK.md`에 정리했습니다.
